# 🐾 PetLife — AI-экосистема для владельцев питомцев

**MVP студенческого стартап-проекта.** Не слайды, а полностью работающий продукт: погода для безопасных прогулок, здоровье с ИИ-анализом фото, питание, дрессировка, трекеры, карта района, форум, маркетплейс и социальная миссия — в одном интерфейсе.

```
42 функции ТЗ  ·  12 разделов кабинета  ·  54 экрана  ·  ~290 интерактивных действий
0 внешних библиотек  ·  0 сборщиков  ·  работает даже без ключей API
```

---

## 🚀 Быстрый запуск (30 секунд)

### Вариант 1 — Windows: двойной клик
```
start.bat
```
Скрипт сам найдёт Python, поднимет сервер и откроет браузер.

### Вариант 2 — терминал (любая ОС)
```bash
cd petlife-mvp
python server.py
```
Если `python` открывает Microsoft Store (заглушка Windows), используйте:
```bash
py -3 server.py
```
Затем откройте **http://127.0.0.1:8765/**

Полезные флаги:
```bash
python server.py --no-browser     # не открывать браузер автоматически
set PETLIFE_PORT=9000 && python server.py   # другой порт (Windows)
PETLIFE_PORT=9000 python3 server.py         # другой порт (Linux/macOS)
```

Порт занят — сервер сам найдёт свободный (8765 → 8766 → …).

> **Можно вообще без сервера:** откройте `index.html` двойным кликом. Сайт, кабинет, ИИ-демо и все трекеры работают, погода запрашивается напрямую у Open-Meteo. Через сервер доступны ещё прокси OpenWeather/OpenRouter и сохранение заявок в файл.

**Требования:** Python 3.9+ (только стандартная библиотека, `pip install` не нужен) и любой современный браузер.

## 🔑 Ключи API (необязательно)

PetLife полностью работает **без ключей**: погода и качество воздуха берутся из открытого Open-Meteo, а ИИ-анализ фото выполняет локальный анализатор изображения. Ключи включают «взрослые» режимы.

Ключи можно задать **тремя способами** — сервер проверяет их по порядку:

| Способ | Как |
|---|---|
| 1. `js/config.js` | откройте файл и вставьте ключ в кавычки |
| 2. `keys.json` | скопируйте `keys.example.json` → `keys.json` и впишите ключи |
| 3. Переменные окружения | `PETLIFE_OPENWEATHER_KEY`, `PETLIFE_OPENROUTER_KEY` |

### OpenWeather (погода, опционально)
1. Зарегистрируйтесь: https://home.openweathermap.org/users/sign_up
2. Ключ: https://home.openweathermap.org/api_keys (активируется 10–60 минут)
3. Вставьте в `js/config.js`:
```js
OPENWEATHER_API_KEY: "ваш_ключ",
```

### OpenRouter (vision-ИИ и ИИ-ассистент, опционально)
1. Зарегистрируйтесь: https://openrouter.ai/
2. Ключ: https://openrouter.ai/keys (модели с суффиксом `:free` бесплатны)
3. Вставьте в `js/config.js`:
```js
OPENROUTER_API_KEY: "sk-or-v1-...",
OPENROUTER_MODEL: "meta-llama/llama-3.2-11b-vision-instruct:free",
```

Проверка, что ключи подхватились: раздел **«Данные и настройки» → Проверить связь с сервером** или http://127.0.0.1:8765/api/health

## 🌐 API сервера

| Метод | Адрес | Что делает |
|---|---|---|
| GET | `/api/health` | версия, источники данных, наличие ключей, число заявок |
| GET | `/api/weather?city=Москва` | погода + почасовой прогноз + AQI/UV/пыльца (OpenWeather или Open-Meteo) |
| POST | `/api/analyze` | `{image: "data:image/..."}` → анализ фото (OpenRouter vision / локальный) |
| POST | `/api/ai/chat` | `{question, context, history}` → ответ ИИ-ассистента |
| POST | `/api/access` | заявка на ранний доступ → `data/signups.json` |
| GET | `/api/signups` | список заявок (последние 50) |

Все ключи остаются на локальном сервере: в браузер они не попадают, если заданы через `keys.json` или переменные окружения.

## ❓ Если что-то не работает

| Симптом | Решение |
|---|---|
| `python: command not found` | установите Python 3.9+ с python.org, отметьте «Add Python to PATH», либо запустите `py -3 server.py`, либо `start.bat` |
| Команда `python` открывает Microsoft Store | это заглушка Windows: используйте `py -3 server.py` или `start.bat` |
| Порт занят | сервер сам возьмёт следующий свободный; можно задать `PETLIFE_PORT` |
| «Не удалось получить погоду» | проверьте интернет; в окне ошибки есть кнопка **«Показать демо-данные»** — сайт продолжит работать |
| ИИ отвечает шаблонно | это локальная база знаний: ключ OpenRouter не указан (см. выше) |
| Фото анализируется локально | норма без ключа: анализатор считает яркость, красноту, желтизну и детализацию кадра |
| Нужно сбросить данные | *Данные и настройки → Вернуть демо-данные* (или *Начать с чистого листа*) |
| Хочу показать заново «как в первый раз» | очистите localStorage для сайта или нажмите *Начать с чистого листа* |

## 💡 Что можно развить дальше (не реализовано намеренно)

- **Настоящие аккаунты и синхронизация.** Сейчас данные локальны (localStorage) — это осознанный выбор для демо. Следующий шаг: FastAPI + PostgreSQL + JWT, синхронизация между телефоном и компьютером.
- **Мобильное приложение.** PWA-манифест + офлайн-кэш + push-напоминания о лекарствах и прогулках (сейчас напоминания видны только внутри интерфейса).
- **Реальный GPS и трекинг.** Интеграция с ошейниками (Tractive, Fi) и построение маршрута по фактическим координатам, а не по модели.
- **Ветеринарный кабинет.** Личный кабинет врача: видеть отчёты питомцев, вести назначения, принимать записи — двусторонняя интеграция вместо односторонней.
- **Онлайн-запись в клиники и груминг.** Сейчас слоты демонстрационные; дальше — реальные слоты партнёров, оплата и подтверждение.
- **ML вместо правил.** Сейчас индекс и рекомендации строятся на формулах и справочниках. Дальше — модель, обученная на обезличенных данных: предсказание рисков по породе, возрасту, весу и динамике симптомов.
- **Улучшение vision-анализа.** Специализированная модель для дерматологии и офтальмологии питомцев с разметкой областей на фото и сравнением с предыдущими снимками («стало лучше/хуже»).
- **Сообщество 2.0.** Реальные ветки форума, подписки, личные сообщения, модерация, рейтинг авторов, совместные прогулки по геолокации.
- **Маркетплейс с оплатой.** Корзина уже работает; дальше — платежи, подписка, партнёрские склады, автозаказ корма по графику.
- **Геймификация.** Достижения, серии, уровни питомца, соревнования между владельцами, награды от партнёров.
- **Социальная миссия в масштабе.** Прозрачные отчёты приютов, публичная статистика пожертвований, налоговые документы, программа «5% с каждой подписки» с аудитом.
- **Локализация и доступность.** Английский язык, единицы измерения (фунты/футы), поддержка скринридеров, тёмная тема.

Идеи на защиту: подчёркивайте не количество кнопок, а **единый профиль питомца**, который связывает все разделы (погода → прогулка → трекер → индекс → рекомендация ИИ), и **социальную миссию**, встроенную в продукт, а не приклеенную сбоку.

## 🛠 Технологии

- **Фронтенд:** чистый HTML5 + CSS3 (переменные, grid/flex, анимации, `prefers-reduced-motion`) + vanilla JavaScript (ES2018+), без React/Vue/сборщиков. Собственный микро-фреймворк: реестр действий `data-act`, декларативные рендер-функции, SVG-графики (линии, столбцы, пончики, спидометр) вместо chart-библиотек.
- **Бэкенд:** Python 3, только стандартная библиотека (`http.server`, `urllib`, `json`, `threading`) — никаких зависимостей и `pip install`.
- **Данные:** localStorage (профили, трекеры, форум, корзина) + `data/signups.json` на сервере.
- **Внешние API (все открытые):** Open-Meteo (погода, качество воздуха, пыльца), опционально OpenWeather и OpenRouter (`:free` модели).
- **Дизайн:** палитра и типографика из ТЗ (#2C5F8D, #4CAF50, #FF9800, #F8F9FA, Inter), скругления 12–16 px, мягкие тени, mobile-first с брейкпоинтами 768 и 480 px, только emoji и SVG — ни одной внешней картинки.
